# pierinim.github.io

Personal website of Maurizio Pierini, built with Jekyll and the
[Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme.

- `_data/publications.yml`: publications, generated from INSPIRE-HEP
- `_data/talks.yml`: talks, generated from CERN Indico
- `_posts/`: research project pages
- `assets/css/main.scss`: colour overrides (light blue and gray)
