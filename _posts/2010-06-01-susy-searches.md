With the first LHC data I worked on searches for supersymmetry in CMS:

- **Razor.** Together with Caltech colleagues (C. Rogan, M. Spiropulu and others) I worked on
  searches based on the razor kinematic variables (M<sub>R</sub>, R), from the first 7 TeV data
  to Run 2.
- **R-parity-violating SUSY with enhanced third-generation couplings**, e.g. top squarks
  decaying to final states with leptons and b jets.

Selected papers (CMS Collaboration):

- [Inclusive search for supersymmetry using the razor variables at √s = 7 TeV](https://arxiv.org/abs/1212.6961), PRL 111 (2013) 081802
- [Search for top squarks in RPV SUSY using three or more leptons and b-tagged jets](https://arxiv.org/abs/1306.6643), PRL 111 (2013) 221801
- [Search for supersymmetry with razor variables at √s = 7 TeV](https://arxiv.org/abs/1405.3961), PRD 90 (2014) 112001
- [Search for supersymmetry using razor variables in events with b-tagged jets at 8 TeV](https://arxiv.org/abs/1502.00300), PRD 91 (2015) 052018
- [Inclusive search for supersymmetry using razor variables at 13 TeV](https://arxiv.org/abs/1609.07658), PRD 95 (2017) 012003
